## Project Overview

AquaSentry is an **AI‑powered water‑contamination tracking and epidemic early‑warning system** designed for community water monitoring. The system ingests water‑quality telemetry from monitored water sources, aggregates community‑reported symptom counts from associated villages, and incorporates local weather observations to compute a **water-source-level risk indicator**.

The computed risk indicator (a normalized `riskScore` between `0.0` and `1.0` mapped to `LOW`, `MEDIUM`, or `HIGH`) is visualized on an interactive **Assam GIS Dashboard** and triggers notifications. An optional read‑only **NitroStack MCP AI Assistant** provides natural‑language access to the existing data.

> **Data Integrity Notice:** 
> - **Real Geographic Context:** Real Assam geographic locations (e.g., Majuli Island, Deepor Beel wetland, Cachar/Barak River) are used for realistic spatial mapping.
> - **Simulated Hardware:** Physical sensors are **not** currently installed in Assam; all telemetry is generated by an IoT simulator.
> - **Prototype Association:** Village → Water Source drinking dependencies are modeled as prototype associations for system demonstration.
> - **Non-Diagnostic:** The system provides early-warning anomaly indicators, **not** clinical disease diagnoses, individual health predictions, or medically validated probabilities.

## 1. System Data & Domain Flow

```
Real Assam Geography
        ↓
     Villages (Kamalabari, Salmora, Pamohi, Sonabarighat, etc.)
        ↓ (Prototype Association)
   Water Sources (Brahmaputra Majuli Reach, Deepor Beel, Barak River)
        ↓
Simulated Sensor Nodes (NODE001, NODE002, NODE003)
        ↓
   Water Readings (ph, tds, turbidity, temperature)
        +
  Village Symptoms (feverCount, diarrheaCount, vomitingCount, abdominalPainCount)
        +
     Weather (temperature, precipitation, humidity)
        ↓
 Isolation Forest AI Engine (11-Feature Vector)
        ↓
 riskScore (0.0 – 1.0) & riskLevel (LOW / MEDIUM / HIGH)
        ↓
Assam GIS Dashboard (Risk Overlays + Alerts)
```

## 2. Key Features

- **Real Assam Geographic Context**: Integrates authentic settlements and water bodies across 3 distinct ecological regions (Majuli River Island, Kamrup Metro Ramsar Wetland, Cachar River Basin).
- **Simulated IoT Telemetry**: Emits realistic `ph`, `tds`, `turbidity`, and `temperature` data for prototype sensor nodes (`NODE001`, `NODE002`, `NODE003`).
- **RESTful API**: Endpoints for villages (`/api/villages`), water sources (`/api/water-sources`), telemetry ingestion (`/api/sensor`), symptom reports (`/api/symptom`), weather cache (`/api/weather`), and risk retrieval (`/api/risk`).
- **MongoDB Persistence**: 8 structured collections (`villages`, `waterSources`, `sensorNodes`, `waterReadings`, `symptoms`, `weather`, `riskScores`, `alerts`) with geospatial 2dsphere indexing.
- **Isolation Forest ML Pipeline**: Unsupervised multi-modal anomaly scoring over exactly **11 features** without demographic or clinical assumptions.
- **Assam GIS Map**: Visualizes monitored water bodies, simulated nodes, associated village catchments, and risk status (🟢 LOW, 🟡 MEDIUM, 🔴 HIGH, ⚪ UNMONITORED).
- **NitroStack MCP Assistant**: Read-only AI Assistant with specialized tools for querying telemetry, symptoms, weather, and contributing risk factors.

## 3. Approved Machine Learning Pipeline

The ML pipeline is defined in `AI_ML_SPEC.md`:
- **Model**: `sklearn.ensemble.IsolationForest` (unsupervised anomaly detection).
- **11 Numerical Features**:
  1. `ph` (water)
  2. `tds` (water)
  3. `turbidity` (water)
  4. `temperature` (water)
  5. `feverCount` (symptoms)
  6. `diarrheaCount` (symptoms)
  7. `vomitingCount` (symptoms)
  8. `abdominalPainCount` (symptoms)
  9. `temperature` (weather ambient)
  10. `precipitation` (weather rainfall)
  11. `humidity` (weather relative humidity)
- **Output**: `riskScore` (`0.0` to `1.0`) and `riskLevel` (`LOW < 0.40`, `MEDIUM 0.40 – 0.69`, `HIGH >= 0.70`) assigned to the monitored **Water Source**.

## 4. MCP AI Assistant Layer

The MCP Assistant runs as an independent read-only layer:

```
User Query
    ↓
AI Assistant
    ↓
NitroStack MCP Server
    ↓
Read‑Only Tools (get_location_risk, get_water_readings, get_symptom_data, get_weather, get_risk_history, get_contributing_factors)
    ↓
Backend REST API
    ↓
MongoDB
```

- Strictly **read-only**; never creates, alters, or deletes data, and does not generate risk scores.
- Zero direct exposure to MongoDB credentials.
